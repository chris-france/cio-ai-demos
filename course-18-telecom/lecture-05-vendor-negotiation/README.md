# Lecture 5 Demo — Vendor Negotiation Intelligence

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A vendor negotiation platform compares carrier pricing, SLA performance, and generates specific negotiation strategies with talking points.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "Carriers count on you not knowing market rates. Walking into a renewal with data is the difference between a 3% and a 25% discount."
