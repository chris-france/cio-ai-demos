# Lecture 1 Demo — The Telecom Chaos

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A single prompt builds a complete telecom circuit inventory dashboard with KPI cards, carrier spend breakdown, circuit type distribution, a sortable inventory table, and a contract expiration timeline. Most CIOs discover 15-20% waste on the first audit.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "Most organizations are paying for circuits nobody uses. A single inventory audit typically finds 15-20% in immediate savings."
