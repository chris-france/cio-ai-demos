# Lecture 2 Demo — AI Circuit Discovery

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

AI network scanning discovers circuits missing from your inventory. Shadow circuits, forgotten backup links, and rogue connections get mapped and costed.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "If your circuit inventory lives in a spreadsheet, it's already wrong. AI discovery finds what humans forgot to document."
