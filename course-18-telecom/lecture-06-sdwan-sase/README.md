# Lecture 6 Demo — SD-WAN & SASE Migration

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A migration readiness assessment compares MPLS costs against SD-WAN alternatives, evaluates site readiness, and builds a phased migration plan with ROI projections.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "SD-WAN isn't just about cost savings -- it's about agility. But migrating without a readiness assessment is how you get outages."
