# Lecture 4 Demo — Bandwidth Optimization

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Bandwidth utilization analysis reveals over-provisioned circuits bleeding money and generates rightsizing recommendations with projected savings.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "Paying for 1 Gbps when you peak at 200 Mbps is like renting a warehouse for a closet. Rightsizing is the fastest ROI in telecom."
