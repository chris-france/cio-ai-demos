# Lecture 3 Demo — Contract Lifecycle Management

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A contract lifecycle dashboard tracks every telecom agreement with renewal alerts, auto-renewal traps, and renegotiation windows. Never miss a renewal deadline again.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "Auto-renewal clauses are designed to benefit the carrier, not you. A contract calendar is the simplest tool that saves the most money."
