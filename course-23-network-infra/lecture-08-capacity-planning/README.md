# Lecture 8 Demo — Network Monitoring & Capacity Planning

**Time:** ~10 minutes | **Tool:** Claude Code

## What This Proves

You can build a network capacity forecasting dashboard with alerting rules — predicting when you'll run out of bandwidth, ports, or throughput before it becomes a crisis.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

## CIO Takeaway

> "Capacity planning isn't about buying more bandwidth — it's about knowing when you'll need it and having the budget approved before the crisis hits."
