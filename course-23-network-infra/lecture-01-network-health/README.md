# Lecture 1 Demo — The Invisible Infrastructure

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a network health dashboard showing switches, routers, uptime, and utilization — making the invisible infrastructure visible and manageable.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.
