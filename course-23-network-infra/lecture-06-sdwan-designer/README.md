# Lecture 6 Demo — SD-WAN Architecture

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can design an SD-WAN architecture and compare providers — replacing expensive MPLS circuits with intelligent, software-defined networking.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## CIO Takeaway

> "MPLS is the mainframe of networking — reliable, expensive, and about to be replaced. SD-WAN gives you the same reliability at a fraction of the cost."
