# Lecture 1 Demo — The AI Wild West

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can audit how AI tools are actually being used across your organization — sanctioned and unsanctioned usage patterns, data exposure risks, and the gap between your AI policy and reality.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-14-ai-governance/lecture-01-shadow-ai-audit. Build a Shadow AI Audit Dashboard with 8 AI tools showing user counts, data types shared, policy status, and risk levels. Include department heatmap and adoption timeline. Generate index.html and open in browser.
