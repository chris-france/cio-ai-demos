# Lecture 1 Demo — The Shadow IT Iceberg

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a shadow IT discovery dashboard revealing the full iceberg — sanctioned apps on top, unsanctioned and unknown below the waterline, with spend analysis and data sensitivity classification.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-13-shadow-it-discovery/lecture-01-discovery-dashboard. Build a Shadow IT Discovery Dashboard with 10 apps showing sanctioned/unsanctioned status, user counts, monthly costs, and data sensitivity. Include an iceberg visualization and risk summary. Generate index.html and open in browser.
