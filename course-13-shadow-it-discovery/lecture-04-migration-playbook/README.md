# Lecture 4 Demo — The Migration Playbook

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a migration tracker showing every shadow app's path to a supported platform — status tracking, user communication plans, and data migration progress all in one view.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-13-shadow-it-discovery/lecture-04-migration-playbook. Build a Shadow IT Migration Playbook with 8 apps showing target platforms, migration status, user counts, and a Kanban-style board. Generate index.html and open in browser.
