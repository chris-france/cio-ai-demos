# Lecture 4 Demo — The Fear Factor

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a team sentiment analyzer with a communication planner that surfaces resistance patterns and generates targeted messaging. The dashboard turns anonymous survey data into an actionable change management plan.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway
