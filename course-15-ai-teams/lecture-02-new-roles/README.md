# Lecture 2 Demo — The New IT Roles

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a role evolution matrix showing which IT roles are growing, shrinking, and emerging. The dashboard maps current headcount against future needs — giving a CIO a workforce planning tool in minutes.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "The org chart you have today won't work in 18 months. This matrix shows you exactly which roles to invest in, which to sunset, and which to create."
