# Lecture 6 Demo — Building an AI Champions Network

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a champions network mapper that visualizes AI advocates across departments and tracks their activities. The dashboard shows influence patterns and adoption velocity.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "Adoption spreads through people, not mandates. This map shows you who your champions are and how to amplify their impact."
