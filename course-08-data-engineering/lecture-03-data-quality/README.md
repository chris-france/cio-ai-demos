# Lecture 3 Demo — Data Quality Monitoring

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Bad data costs more than no data. This scorecard measures every data source across four dimensions — completeness, accuracy, freshness, and consistency — grading each source and surfacing the critical quality issues that silently corrupt your analytics.

## Run the Demo

Open any terminal. Type `claude`. Paste this:
