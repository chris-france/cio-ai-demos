# Lecture 7 Demo — Building Your Data Platform

**Time:** ~10 minutes | **Tool:** Claude Code

## What This Proves

A data platform is not a product you buy — it is an architecture you build across six layers. This assessment scores your current maturity, maps each component to a tool, and generates a phased roadmap prioritizing open source to minimize vendor lock-in.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-08-data-engineering/lecture-07-data-platform.
>
> Build me a Data Platform Architecture Assessment as a single index.html using Tailwind CSS and Chart.js from CDN. Score 6 platform layers with radar chart, show architecture components, and generate a 3-phase implementation roadmap with budget estimates.
