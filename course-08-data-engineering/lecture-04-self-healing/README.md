# Lecture 4 Demo — Self-Healing Pipelines

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Pipeline failures at 3 AM should not require an engineer at 3 AM. This simulator shows AI detecting failures, diagnosing root causes, and applying automatic fixes — from API rate limits to schema changes to duplicate records.
