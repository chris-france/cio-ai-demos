# Lecture 1 Demo — The Pipeline Problem

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Most organizations have no visibility into their data pipelines. This dashboard shows every pipeline, its health, schedule, latency, and failure history — exposing the silent breakages that corrupt your reports and dashboards.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-08-data-engineering/lecture-01-pipeline-health.
>
> Build me a Data Pipeline Health Dashboard as a single index.html using Tailwind CSS and Chart.js from CDN. Show 12 pipelines with source, destination, schedule, status, duration, and record counts. Include a success rate trend chart and status distribution.
