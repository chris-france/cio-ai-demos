# Lecture 6 Demo — Schema Evolution Management

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Schema changes are the silent killer of data pipelines. When a source system adds a column, changes a type, or renames a field, downstream pipelines break. This tracker detects changes automatically, classifies impact, and auto-adapts when possible.

## Run the Demo

Open any terminal. Type `claude`. Paste this:
