# Lecture 7 Demo — Data Storytelling

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Charts and tables are not stories. This generator takes raw business metrics and produces an executive narrative — what happened, why it matters, and what to do about it. The kind of report your board expects, generated in seconds.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-07-business-analytics/lecture-07-narrative-report.
>
> Build me a Narrative Report Generator as a single index.html using Tailwind CSS and Chart.js from CDN. Include Q1 business metrics, charts for revenue by segment and customer health, and a full AI-generated executive narrative with what went right, what needs attention, and recommended actions.
