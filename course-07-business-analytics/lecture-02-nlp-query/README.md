# Lecture 2 Demo — Natural Language Querying

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Business users should not need SQL to get answers from their data. This simulator shows how natural language queries get translated to SQL, executed, and returned as charts and tables — no data analyst required.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-07-business-analytics/lecture-02-nlp-query.
>
> Build me an NLP Query Simulator as a single index.html using Tailwind CSS and Chart.js from CDN. Include a text input for natural language questions, show the generated SQL, display results as both chart and table, and add AI-generated insights.
