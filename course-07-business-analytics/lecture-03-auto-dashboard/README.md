# Lecture 3 Demo — Self-Building Dashboards

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

AI can scan your data sources, detect the most important KPIs, choose the right chart types, and build a complete executive dashboard — no analyst intervention required. The dashboard explains what it found and why it chose each visualization.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-07-business-analytics/lecture-03-auto-dashboard.
>
> Build me a Self-Building KPI Dashboard as a single index.html using Tailwind CSS and Chart.js from CDN. Simulate scanning 4 data sources, detecting 12 KPIs, and auto-generating charts. Show the data source for each chart and AI confidence scores.
