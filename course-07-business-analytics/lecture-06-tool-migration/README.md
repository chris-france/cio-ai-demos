# Lecture 6 Demo — Replacing Tableau and Power BI

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Traditional BI tools are expensive, underutilized, and require specialized skills. This comparison and migration calculator shows the cost difference, feature gaps, and a concrete migration plan for moving to AI-native analytics.

## Run the Demo
