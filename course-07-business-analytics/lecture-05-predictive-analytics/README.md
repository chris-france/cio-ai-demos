# Lecture 5 Demo — Predictive Analytics Without Data Science

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You do not need a data science team to get revenue forecasts and churn predictions. AI can analyze your historical data, project trends with confidence intervals, and flag at-risk customers with specific recommended actions.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-07-business-analytics/lecture-05-predictive-analytics.
>
> Build me a Revenue & Churn Prediction Dashboard as a single index.html using Tailwind CSS and Chart.js from CDN. Show 6-month revenue forecast with confidence bands, churn prediction by segment, and an at-risk customer table with probability scores and recommended actions.
