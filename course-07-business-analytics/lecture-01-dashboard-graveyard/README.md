# Lecture 1 Demo — The Dashboard Graveyard

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Most organizations have more dead dashboards than active ones. This audit catalogs every dashboard across Tableau, Power BI, Looker, and Sheets — revealing which ones nobody uses, what they cost, and how much you are wasting on analytics nobody looks at.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-07-business-analytics/lecture-01-dashboard-graveyard.
>
> Build me a Dashboard Utilization Audit as a single index.html using Tailwind CSS and Chart.js from CDN. Show all 18 dashboards with views, unique users, platform, cost, and status. Flag dead dashboards and calculate wasted spend.
