# Lecture 5 Demo — Escalation Intelligence

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

When a ticket must escalate to a human, the AI packages full context — customer history, related incidents, steps already tried, and business impact — so the specialist can start solving immediately instead of spending 20 minutes investigating. No more "can you explain the problem again?"

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-03-service-mgmt/lecture-05-escalation.
>
> Build me an escalation intelligence demo as a single index.html using Tailwind CSS and Chart.js. Show a workflow visualization: ticket comes in, AI analyzes severity and confidence, packages full context (customer history, similar incidents, attempted solutions, business impact), then routes to the right specialist with a warm handoff message. Include 3 example escalations: a recurring network issue, a VIP executive laptop failure, and a data loss incident. For each, show the priority score breakdown and a comparison chart of traditional vs AI-powered escalation metrics.
