# Lecture 4 Demo — Knowledge Base Generator

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Every resolved ticket can automatically become a knowledge base article. The demo takes 5 real resolved tickets and generates complete KB articles — with titles, summaries, step-by-step instructions, tags, and estimated ticket deflection rates. One click to approve and publish. No more knowledge base graveyards.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-03-service-mgmt/lecture-04-kb-generator.
>
> Build me a knowledge base generator demo as a single index.html using Tailwind CSS and Chart.js. Two-panel layout: left panel shows 5 resolved tickets (VPN cert error, Outlook search broken, new hire onboarding, printer offline, MFA push not working). When I click a ticket, the right panel generates a complete KB article with title, category badge, summary, numbered step-by-step instructions, tags, estimated ticket deflection, and source ticket reference. Include an "Approve & Publish" button. Show stats at the top: articles generated, estimated tickets deflected per month, average generation time (under 2 seconds), and comparison to manual authoring time (45 min per article).
