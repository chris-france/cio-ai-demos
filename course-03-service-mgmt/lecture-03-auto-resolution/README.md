# Lecture 3 Demo — Auto-Resolution: The 70% Rule

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

AI can resolve 70% of help desk tickets without a human touching them. The demo processes 10 tickets in real time — 7 get auto-resolved with specific methods (password resets, software deploys, certificate renewals), while 3 escalate to humans because the confidence is too low or the issue requires physical intervention.
