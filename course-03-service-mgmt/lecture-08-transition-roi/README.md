# Lecture 8 Demo — Transition Plan and ROI Calculator

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

The transition from a traditional help desk to AI-powered operations follows a proven 90-day playbook: shadow, assist, auto. The ROI calculator lets any CIO plug in their own numbers and see exactly when the investment pays for itself — typically within 3-5 months.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-03-service-mgmt/lecture-08-transition-roi.
>
> Build me a transition plan and ROI calculator as a single index.html using Tailwind CSS and Chart.js. Two sections: (1) An ROI Calculator with sliders for monthly ticket volume, cost per ticket, target automation rate (20-80%), current staff count, and AI platform cost. Show projected savings, break-even point, ROI percentage, and a cumulative savings chart over 12 months. (2) A 90-day implementation roadmap with three phases — Month 1 Shadow Mode, Month 2 Assist Mode, Month 3 Auto Mode — shown as cards plus a detailed week-by-week timeline. Add charts showing expected metrics by week (accuracy, auto-resolution rate, CSAT) and team composition transition over 12 months.
