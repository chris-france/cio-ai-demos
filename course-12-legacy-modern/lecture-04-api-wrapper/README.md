# Lecture 4 Demo — API Wrapping Legacy Systems

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can wrap legacy systems with modern REST APIs without rewriting them — health monitoring, usage metrics, latency tracking, and error rates making old systems accessible to new consumers.
