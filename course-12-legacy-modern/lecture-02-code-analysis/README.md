# Lecture 2 Demo — AI Reads Your Legacy Code

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

AI can analyze a legacy codebase and produce a comprehensive report — language breakdown, complexity metrics, documentation coverage, dependency risks, and migration readiness score — turning weeks of manual analysis into minutes.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-12-legacy-modern/lecture-02-code-analysis. Build a Legacy Code Analysis Report showing 6 modules with language, lines of code, cyclomatic complexity, documentation coverage, and test status. Include a language breakdown donut chart, complexity ranking bar chart, and migration complexity matrix. Generate index.html and open in browser.
