# Lecture 1 Demo — The Legacy Trap

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a legacy system inventory dashboard that reveals every aging system in your portfolio — age, annual maintenance cost, risk scores, and business criticality — giving your board the complete picture they need to fund modernization, all generated by AI in minutes.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-12-legacy-modern/lecture-01-legacy-inventory. Build a Legacy System Inventory Dashboard showing 8 systems with age, annual cost, risk score (1-10), criticality level, and vendor support status. Include KPI cards, a cost-vs-risk scatter plot, a sortable table, and an executive summary. Generate index.html and open in browser.
