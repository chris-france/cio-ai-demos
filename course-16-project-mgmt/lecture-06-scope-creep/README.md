# Lecture 6 Demo — Scope Creep Detection

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a scope change tracker that detects and quantifies scope creep in real time. The dashboard shows the cumulative impact of "small" changes on budget and timeline.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "Scope creep is death by a thousand cuts. This tracker makes every cut visible — and quantifies what each one costs."
