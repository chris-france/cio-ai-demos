# Lecture 4 Demo — Resource Optimization

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a resource allocation heatmap showing utilization across projects and teams. The dashboard identifies overallocation, bench time, and optimization opportunities.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "You can't optimize what you can't see. This heatmap shows where people are overworked and where capacity is wasted."
