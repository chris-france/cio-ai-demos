# Lecture 1 Demo — Why IT Projects Still Fail

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a project failure risk dashboard that scores active projects across scope, budget, and timeline risk factors. The dashboard surfaces troubled projects before they become crises.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "Projects don't fail on the last day — they fail slowly, invisibly. This dashboard makes the warning signs visible while there's still time to act."
