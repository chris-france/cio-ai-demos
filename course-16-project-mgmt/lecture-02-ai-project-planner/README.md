# Lecture 2 Demo — AI Project Planning

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build an AI project plan generator that creates milestones, dependencies, and resource assignments from a project description. The dashboard produces a visual project plan in minutes.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "The best project plans are living documents. This generator creates a baseline you can iterate on — not a static Gantt chart that's outdated by Monday."
