# Lecture 5 Demo — Compliance Automation

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

AI maps your security controls across five compliance frameworks simultaneously, identifies overlapping requirements, and highlights the quick wins that move the needle across all frameworks at once — turning annual audit panic into a continuous dashboard.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-05-security-ops/lecture-05-compliance-dashboard. Build a Multi-Framework Compliance Dashboard. Map 30 security controls across SOC 2, HIPAA, PCI-DSS, GDPR, and NIST CSF. Color-code each: compliant (green), partial (yellow), non-compliant (red), N/A (gray). Show overall scores per framework, a gap analysis with quick wins, and a compliance trend chart. Create index.html and open in browser.
