# Lecture 3 Demo — Phishing Defense

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

AI can analyze emails with contextual understanding that traditional spam filters lack — catching domain typosquats, BEC patterns, and social engineering tactics while explaining exactly why each email is flagged, with zero false positives.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-05-security-ops/lecture-03-phishing-classifier. Build an AI Phishing Classifier that analyzes 10 emails — a mix of legitimate, suspicious, and phishing. For each email show: sender, subject, preview, AI classification (safe/suspicious/phishing), confidence score, and red flags identified. Create index.html with email cards, summary stats, and a comparison chart vs traditional filters. Open in browser.
