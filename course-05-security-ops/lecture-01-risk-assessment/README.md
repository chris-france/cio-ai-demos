# Lecture 1 Demo — The SMB Security Gap

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a comprehensive security risk assessment dashboard that scores your organization across 8 categories, visualizes risk on a radar chart and likelihood-vs-impact matrix, and prioritizes the top findings with actionable recommendations — all generated by AI in minutes.
