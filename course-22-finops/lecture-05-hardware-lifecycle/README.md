# Lecture 5 Demo — Hardware Warranty & Lifecycle

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can track every hardware asset's warranty status, age, and refresh cost — turning reactive break-fix into planned lifecycle management.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.
