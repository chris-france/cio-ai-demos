# Lecture 1 Demo — The IT Finance Black Box

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a complete IT financial dashboard showing budget vs actual by category, variance analysis, and spend trending — making the IT finance black box transparent.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

2. "Break down the top 3 overspend categories with root cause analysis"
