# Lecture 4 Demo — Renewal & Contract Calendar

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a contract renewal calendar that shows upcoming renewals, auto-renewal risks, and negotiation windows — stopping the silent budget bleed of auto-renewals you never reviewed.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

1. "Flag all contracts with auto-renewal clauses that trigger in the next 90 days"
2. "Calculate the total spend at risk from contracts renewing without review"
3. "Build a negotiation prep sheet for the top 5 upcoming renewals"

## CIO Takeaway

> "Auto-renewals are the silent killer of IT budgets. If you don't know what's renewing next month, you're already paying too much."
