# Lecture 6 Demo — Chargeback & Showback Models

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build an IT cost allocation dashboard that shows each business unit exactly what they consume and what it costs — ending the "IT is too expensive" argument with data.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

1. "Add a comparison showing what each BU would pay for the same services from a public cloud provider"
2. "Build a per-user cost breakdown showing the true cost of IT per employee by department"
3. "Create a showback report template I can send to each BU leader monthly"

## CIO Takeaway

> "When business units see what they consume, consumption drops 15-25%. Showback changes behavior without changing budgets."
