# Lecture 2 Demo — AI-Powered Invoice Processing

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build an invoice analysis dashboard that detects anomalies, flags duplicate charges, and identifies billing errors — the kind of analysis that pays for itself on the first invoice.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.
