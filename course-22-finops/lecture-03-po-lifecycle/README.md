# Lecture 3 Demo — Purchase Order Lifecycle

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can track every PO from request through approval to delivery, identifying bottlenecks and aging items that are burning budget without delivering value.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

1. "Show me the average approval time by department and flag the slowest approvers"
2. "Build an aging report for POs stuck in approval for more than 30 days"
3. "Create an automated escalation rule set for stalled purchase orders"

## CIO Takeaway

> "A PO that takes 6 weeks to approve costs more than the purchase itself. Speed is savings."
