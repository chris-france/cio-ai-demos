# Lecture 3 Demo — License Optimization

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a license harvesting dashboard that identifies unused, underused, and overprovisioned software licenses. The dashboard quantifies savings from license optimization.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "Most organizations waste 25-30% of their software licenses. This dashboard finds the waste and calculates the savings."
