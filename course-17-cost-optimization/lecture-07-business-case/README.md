# Lecture 7 Demo — Building the Business Case

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a cost optimization business case generator that pulls together savings opportunities into a CFO-ready presentation. The dashboard calculates ROI, payback period, and implementation costs.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "CFOs don't fund feelings — they fund business cases. This generator turns your optimization findings into a document that gets budget approved."
