# Lecture 1 Demo — The IT Spending Black Hole

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build an IT spend breakdown dashboard showing spending by category and trend. The dashboard reveals where money disappears and which cost centers are growing fastest.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "You can't cut costs you can't see. This dashboard gives you the complete picture of where every IT dollar goes."
