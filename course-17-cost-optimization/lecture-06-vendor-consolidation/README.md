# Lecture 6 Demo — Vendor Consolidation

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a vendor overlap detector that identifies redundant tools and consolidation opportunities. The dashboard maps vendor capabilities and calculates consolidation savings.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo portal.

## CIO Takeaway

> "Most CIOs have 3-5 tools doing the same job. This detector finds the overlap and builds the consolidation plan."
