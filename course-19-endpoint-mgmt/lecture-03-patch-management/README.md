# Lecture 3 Demo — Patch Management That Actually Works

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A patch compliance dashboard shows what's patched, what's not, and why -- with compliance rates by OS, criticality breakdown, and aging patches.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "Patch compliance isn't about hitting 100% -- it's about knowing exactly where you're not and having a plan for every exception."
