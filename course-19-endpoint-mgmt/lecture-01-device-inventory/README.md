# Lecture 1 Demo — The Endpoint Explosion

**Time:** ~8 minutes | **Tool:** Claude Code

An endpoint inventory dashboard reveals every device type, OS version, compliance status, and management state. Most organizations discover 20-30% more devices than expected.
