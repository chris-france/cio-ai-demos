# Lecture 5 Demo — BYOD Without the Risk

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A BYOD compliance dashboard checks personal devices against your policy with encryption, OS version, MDM enrollment, and risk scoring.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "BYOD saves money only if you manage the risk. An unmanaged personal device with corporate email is a breach waiting to happen."
