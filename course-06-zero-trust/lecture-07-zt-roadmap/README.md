# Lecture 7 Demo — Your Zero Trust Roadmap

**Time:** ~10 minutes | **Tool:** Claude Code

## What This Proves

Zero trust is not a product you buy — it is a maturity journey across seven pillars. This assessment scores your current state, identifies gaps, and generates a phased roadmap with budget estimates. It turns an abstract framework into concrete action items.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-06-zero-trust/lecture-07-zt-roadmap.
>
> Build me a Zero Trust Maturity Assessment as a single index.html using Tailwind CSS and Chart.js from CDN. Score 7 zero trust pillars (Identity, Devices, Network, Applications, Data, Visibility, Automation) with current vs target radar chart, a 4-phase implementation roadmap, and a detail table with gap analysis and priority actions.
