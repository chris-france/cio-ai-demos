# Lecture 4 Demo — Access Reviews Without the Pain

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Quarterly access reviews are a compliance nightmare because they treat every entitlement equally. This dashboard uses risk scoring to prioritize reviews — critical risks first, auto-approve low-risk active accounts, and flag unused access for immediate revocation.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-06-zero-trust/lecture-04-access-review.
>
> Build me an Access Review Dashboard as a single index.html using Tailwind CSS and Chart.js from CDN. Show pending reviews with AI risk scores based on usage patterns, access level, and account type. Include risk filtering, department breakdown, and inline approve/revoke/reduce decisions.
