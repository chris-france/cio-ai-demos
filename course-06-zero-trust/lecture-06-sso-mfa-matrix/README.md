# Lecture 6 Demo — SSO and MFA Strategy

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Most organizations have a patchwork of authentication methods across their application portfolio. This matrix shows exactly which apps have SSO, which have MFA, which have both, and which have neither — exposing the gaps that attackers exploit.
