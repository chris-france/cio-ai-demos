# Lecture 2 Demo — Identity is the New Perimeter

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Identity is the most exploited attack vector. This dashboard audits every account in your directory — MFA coverage gaps, stale accounts that should have been disabled months ago, admin sprawl, and shared credentials that bypass all accountability.

## Run the Demo

Open any terminal. Type `claude`. Paste this:

> Find the cio-ai-demos repo on my machine. Inside it, go to course-06-zero-trust/lecture-02-identity-audit.
>
> Build me an Identity Audit Dashboard as a single index.html using Tailwind CSS and Chart.js from CDN. I need to see MFA coverage by department, stale account counts, admin account sprawl, and shared accounts. Include a user table with risk scores and flag badges.
