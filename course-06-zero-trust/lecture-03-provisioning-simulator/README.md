# Lecture 3 Demo — Automated Provisioning

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Manual provisioning takes days and leaves security gaps. This simulator shows a complete automated pipeline — from HR trigger to verified access — completing in minutes what used to take 3+ days, with zero orphaned accounts.
