# Lecture 5 Demo — Privilege Escalation Detection

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

Most breaches involve privilege escalation that goes undetected for weeks. This detector surfaces anomalies like self-escalation, dormant account activation, audit tampering, and unusual data exports — the exact patterns that precede data breaches.
