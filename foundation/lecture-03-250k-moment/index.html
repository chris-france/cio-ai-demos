Quick Win Risk Assessment

What could go wrong with each displacement — and how to prevent it.

Accenture Custom Dev $250,000/yr — Software Development
Quick Win
Severity Risk Impact if Unmitigated Mitigation Plan
HIGH Knowledge loss — Accenture holds undocumented institutional knowledge of legacy systems Critical systems break with no one who understands the codebase. Outages, data loss, scramble to rehire at premium rates. 30-day knowledge transfer period. Require Accenture to document all systems, dependencies, and runbooks before contract winds down. Record handoff sessions. No cutover until internal team demonstrates independent operation.
MED AI coding tools don't match output quality for complex legacy work Internal team ships more bugs. Velocity drops. Stakeholders lose confidence in AI strategy. Parallel run (Days 31-60). Internal AI-augmented team works alongside Accenture on identical tasks. Compare defect rates, velocity, and code quality. Only cutover if metrics meet or exceed baseline.
MED Internal team lacks capacity to absorb the workload Burnout, delays, pressure to re-engage Accenture at renegotiated (higher) rates. Hire 1-2 mid-level developers before cutover ($150-180K total, still net positive vs. $250K contract). AI tools handle ~80% of routine work; humans handle complex architecture decisions.
LOW Contractual lock-in — penalties or IP clauses prevent clean exit Legal dispute delays transition. Unexpected termination fees. Legal review now. Have counsel review the MSA for termination clauses, IP ownership of code, and auto-renewal traps. Start Week 1 — it's the critical path.
Offshore QA Team (TCS) $96,000/yr — Quality Assurance
Quick Win
Severity Risk Impact if Unmitigated Mitigation Plan
HIGH AI testing tools miss edge cases that human testers catch Production bugs increase. Customer-facing defects. Reputational damage and support costs spike. Keep 1 senior QA engineer ($90-110K) to own test strategy, review AI-generated suites, and handle exploratory testing. AI covers regression breadth; human covers depth. Net savings still ~$75K/yr.
MED Test coverage gaps during transition — manual tests not fully converted Blind spots in coverage for 4-8 weeks. Regressions slip through during the most vulnerable period. Require TCS to export all test cases in structured format before contract ends. Map 100% of manual tests to AI-automated equivalents. No cutover until coverage parity is verified. Parallel run for 2 sprint cycles.
MED AI testing tools require significant setup and learning curve Delayed ROI. Team frustration. Pressure to bring back the offshore team. Start the pilot now — during the TCS overlap, not after. Run the AI tool against the same test plans. Measure false positives, coverage, and time-to-result before committing.
LOW Compliance/audit requirements mandate human-reviewed test evidence Auditors reject AI-generated test reports. Compliance finding. Check audit requirements first. If human sign-off is required, the senior QA engineer reviews and approves all AI-generated reports. Process change, not a blocker.
Custom Report Generator $48,000/yr — Internal Reporting
Quick Win
Severity Risk Impact if Unmitigated Mitigation Plan
MED LLM-generated reports contain hallucinated data or calculation errors Executives make decisions on wrong numbers. Trust in AI initiative collapses before it starts. Deterministic pipeline, not freeform generation. LLM formats and narrates — all numbers come from direct database queries, not AI. Automated checksums: totals must match source data or the report flags itself for human review.
MED Report format doesn't match what stakeholders expect Complaints from leadership. "The old reports were better." Resistance to further AI initiatives. Template-driven approach. Capture exact layout, sections, and formatting of current reports as templates. LLM fills in data and narrative within the existing structure. 2 months side-by-side before switching.
LOW Data source access — vendor's tool has database connections that need replication New pipeline can't access the same data. Reports are incomplete or delayed. Map all data sources in Week 1. Document every database, API, and file the current tool pulls from. Replicate connections before building reports. A 2-3 day engineering task.
LOW No one can maintain the LLM pipeline after the builder leaves Pipeline breaks. Slow return to manual process or new vendor. Keep it simple. Python script + Claude API + cron job. No complex frameworks. Single README. Any mid-level developer can maintain it. Total codebase: ~200 lines.
