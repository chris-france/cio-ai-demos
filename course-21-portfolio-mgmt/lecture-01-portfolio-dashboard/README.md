# Lecture 1 Demo — The Portfolio Paradox

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can build a complete IT project portfolio dashboard showing budget, status, alignment scores, and risk — all from a single prompt.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

1. "Add a filter to show only projects at risk of budget overrun"
2. "Create a strategic alignment heatmap showing which projects map to which business goals"
3. "Export the portfolio summary as a board-ready PDF report"

## CIO Takeaway

> "Your portfolio isn't a spreadsheet — it's a living dashboard that shows where every IT dollar is going and whether it's moving the mission forward."
