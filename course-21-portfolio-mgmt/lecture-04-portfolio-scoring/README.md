# Lecture 4 Demo — AI-Powered Portfolio Scoring

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can score every project in your portfolio against multiple criteria — strategic value, financial return, risk, resource availability, and technical complexity — using AI to surface the winners and the dead weight.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

1. "Rank the bottom 5 projects and build a case for killing or pausing each one"
2. "Add a resource constraint — we only have 3 senior developers — and re-score"
3. "Show me the efficient frontier: maximum strategic value for each budget level"

## CIO Takeaway

> "Gut feel doesn't scale. Multi-criteria scoring with AI turns portfolio reviews from political debates into data-driven decisions."
