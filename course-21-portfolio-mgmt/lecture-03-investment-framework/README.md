# Lecture 3 Demo — The Investment Framework

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can categorize your entire IT portfolio into Run/Grow/Transform buckets and visualize the investment split to ensure you're not just keeping the lights on.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

1. "Show me the ideal 60/25/15 split and compare it to our actual allocation"
2. "Flag projects that are categorized as Transform but spending like Run"
3. "Build a migration plan to shift 10% of Run budget to Transform initiatives"

## CIO Takeaway

> "If 85% of your IT budget is Run, you're not a technology leader — you're a facilities manager. The framework makes the imbalance impossible to ignore."
