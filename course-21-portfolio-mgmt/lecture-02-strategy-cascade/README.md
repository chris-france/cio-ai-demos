# Lecture 2 Demo — Mission-to-IT Alignment

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

You can map your organization's mission and strategic goals down through IT initiatives to individual projects, visualizing alignment gaps and orphaned spend.

## Run the Demo

Open any terminal. Type `claude`. Paste the prompt from the course demo launcher.

## Keep Going — Paste These Next

1. "Highlight the IT projects with no strategic alignment — the orphan spend"
2. "Score each project's alignment strength on a 1-10 scale"
3. "Build a Sankey diagram showing budget flow from strategy to projects"

## CIO Takeaway

> "If you can't draw a line from a project to a mission goal, that project shouldn't exist in your portfolio."
