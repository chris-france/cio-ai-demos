# Lecture 6 Demo — Measuring Service Quality

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A service quality scorecard measures customer satisfaction, resolution time, SLA compliance, and first-contact resolution.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway
