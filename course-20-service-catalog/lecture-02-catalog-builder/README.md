# Lecture 2 Demo — Designing Your Service Catalog

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A service catalog builder structures categories, service items, SLA targets, owners, and fulfillment workflows from scratch.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "A service catalog isn't a list of things IT does -- it's a promise to the business. Every service needs an owner, an SLA, and a fulfillment path."
