# Lecture 1 Demo — The IT Request Black Hole

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

A request backlog analyzer reveals the true state of IT service delivery -- pending requests, aging analysis, and SLA breaches.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "If you don't know how many requests are pending and how old they are, your users already think IT doesn't care."
