# Lecture 5 Demo — Approval Workflows Without Bottlenecks

**Time:** ~8 minutes | **Tool:** Claude Code

## What This Proves

An approval workflow analyzer reveals where requests die waiting, which approvers are bottlenecks, and where auto-approval can speed things up.

## Run the Demo

Open any terminal. Type `claude`. Paste the CC prompt from the demo panel.

## CIO Takeaway

> "Most approval workflows were designed for a world of paper forms. If a $50 software request needs VP approval, your workflow is the problem."
